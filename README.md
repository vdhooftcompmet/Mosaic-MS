# Mosaic-MS

> **Integrated Substructure & Motif Mapping for Untargeted Metabolomics**

**Mosaic-MS** is a bioinformatic pipeline that integrates **SNAP-MS** (network-guided structural annotation) and **MS2LDA** (unsupervised Mass Motif discovery) with **Molecular Networking** into a unified structural annotation framework for mass spectrometry data.

---

## Concept & Name

**Mosaic-MS** stands for **MO**_tif mining_ & **S**_NAP-MS_ **A**_nnotation_ **I**_ntegration for_ **C**_hemical discoveries with_ **MS**.

The name reflects the seamless integration of pattern mining and substructure-to-structure annotation approaches in untargeted metabolomics:

* **Pattern Mining (MS2LDA):** Extracts latent fragmentation patterns (**Mass2Motifs**) representing co-occurring fragment/neutral loss motifs across untargeted datasets.
* **Structural Mapping (SNAP-MS):** Maps known compound families onto molecular networks using structural similarity and network topology.

Just as individual tiles come together to form a mosaic, **Mosaic-MS** acts as the unifying framework—assembling motif mining, network topology, and substructure annotations into a single, context-rich chemical network. This integrated approach enables deeper structural insights and streamlined chemical prioritization in Cytoscape.

## Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/vdhooftcompmet/Mosaic-MS.git
cd Mosaic-MS
```

### 2. Set Up the Environment
Choose one of the following methods depending on your package manager preference:

#### Using Conda/Mamba (Recommended):
```bash
conda env create -f environment.yaml
conda activate mosaic-ms
```

#### Using Pip:
```bash
python3.11 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Download Supporting Files
Run the setup script to download required reference datasets, models, and demo files:
```bash
python setup.py
```

## Result Preview

To visualize the enriched network outputs generated by **Mosaic-MS**, you can open the provided example files in **Cytoscape**:

1. **Download Cytoscape:** [cytoscape.org/download.html](https://cytoscape.org/download.html)
2. **Install the ChemViz Extension:**
   * Open Cytoscape.
   * Go to **Apps** $\rightarrow$ **App Store** $\rightarrow$ **Show App Store** (or App Manager).
   * Search for `chemViz2`, select it, and click **Install**. *(This plugin renders 2D chemical structures directly on network nodes).*
3. **Open Example Output Files:**
   * `data/mn_example.cx`: Displays a molecular network enriched with integrated **MS2LDA motifs** and **SNAP-MS metadata**.
   * `data/snapms_example.cx`: Displays detailed SNAP-MS substructure mapping for **Cluster 1** of the example network.

## Running the Pipeline

Navigate into the `src` directory to run the CLI commands individually:

```bash
cd src
```

### CLI Workflow Steps

1. **Run MS2LDA**
   ```bash
   python cli.py run-ms2lda --mgf ../data/test_file.mgf
   ```

2. **Run Molecular Networking**
   ```bash
   python cli.py run-mn --mgf ../data/test_file.mgf
   ```

3. **Run SNAP-MS**
   ```bash
   python cli.py run-snapms --graph ../results/base.cx
   ```

4. **Add MS2LDA Results to Graph**
   ```bash
   python cli.py add-ms2lda --graph ../results/base.cx --model ../results/model.lda 
   ```

5. **Add SNAP-MS Results to Graph**
   ```bash
   python cli.py add-snapms --graph ../results/base.cx --snapms ../results/snapms
   ```
